# Lung Segmentation using U-Net

## Overview
This project applies semantic segmentation techniques to chest X-ray images using the U-Net architecture.

The goal is to accurately identify and isolate lung regions from medical images for use in healthcare and diagnostic applications.

## Technologies
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- OpenCV

## Deep Learning Techniques
- U-Net
- Semantic Segmentation
- Medical Image Processing
- Image Normalization
- Binary Mask Generation

## Workflow
1. Image Preprocessing
2. Dataset Preparation
3. U-Net Model Training
4. Lung Mask Prediction
5. Segmentation Evaluation

## Dataset
Chest X-Ray (CXR) Images with Corresponding Lung Masks

## Applications
- Medical Imaging
- Computer Vision
- Healthcare AI
